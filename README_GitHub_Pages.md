# GitHub Pages site for ASK Alfred.

This is a simple static site for GitHub Pages.

## Files
- `index.html`
- `styles.css`
- `script.js`

## What it does
- Shows **ASK Alfred. 🐧🎩**
- Uses a 1930s cartoon-inspired look
- Uses a large custom cursor
- Includes a clickable `mailto:` link for:
  `foundationsofaiagentsnyu@gmail.com`

Note: on a static GitHub Pages site, the button opens the visitor's email client. It does not directly send email without a backend.
